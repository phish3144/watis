Browser-Erweiterung

Welche Daten die Erweiterung verarbeitet

Die Erweiterung liest auf web.whatsapp.com mit, was WhatsApp Web in deinem Browser ohnehin anzeigt: Nachrichten, Chat- und Kontaktnamen, Telefonnummern, Zeitpunkte und Anhänge wie Bilder, Dokumente und Sprachnachrichten. Daraus baut sie ein durchsuchbares Archiv. Texterkennung in Bildern und PDFs und die Transkription von Sprachnachrichten laufen ebenfalls auf deinem Gerät.

Wo die Daten liegen

Ausschließlich im Speicher der Erweiterung in deinem Browserprofil. Die Erweiterung überträgt keine dieser Daten an uns oder an Dritte. Entfernst du die Erweiterung, löscht der Browser das Archiv.

Eine Sicherung entsteht nur, wenn du sie selbst anstößt: in einen Ordner, den du wählst, oder als Datei in deinen Downloads. Liegt dieser Ordner in einem Cloud-Speicher wie OneDrive oder Nextcloud, gelten für die Kopie dort die Bedingungen dieses Anbieters.

Netzwerkzugriffe

  • web.whatsapp.com und die Medienserver von WhatsApp: Anhänge holt die Erweiterung über WhatsApp Web selbst, auf demselben Weg wie ein Klick auf „Herunterladen“.
  • GitHub, nur wenn du für die Transkription ein Sprachmodell lädst und zustimmst. Dabei erhält GitHub, Inc. wie bei jedem Download deine IP-Adresse; siehe die Datenschutzerklärung von GitHub.

Sonst stellt die Erweiterung keine Verbindungen her.

Wozu die Berechtigungen dienen

  • Zugriff auf web.whatsapp.com: Nachrichten und Anhänge für das Archiv lesen.
  • Speicher, unbegrenzter Speicher: das Archiv und die Medien lokal ablegen.
  • Benachrichtigungen: neue Nachrichten melden; in den Einstellungen abschaltbar.
  • Downloads: Sicherungen und gespeicherte Anhänge als Datei ablegen.
  • Seitenleiste: das Panel neben WhatsApp Web zeigen.
  • GitHub (optional): das Sprachmodell laden. Der Browser fragt dich vorher.

Nachrichten anderer Personen

Dein Archiv enthält auch, was andere dir geschrieben haben. Es bleibt auf deinem Gerät. Gibst du eine Sicherung oder einen Export weiter, gibst du auch diese Nachrichten weiter.

Desktop-App

Für die Desktop-App gilt dasselbe. Sie zeigt WhatsApp Web in einem eigenen Fenster und legt das Archiv nur auf deinem Rechner ab, unter Windows im Ordner %LOCALAPPDATA%\watis. Zusätzlich fragt sie bei GitHub Releases nach, ob es eine neue Version gibt, und lädt Updates von dort. Dabei erhält GitHub deine IP-Adresse.

Diese Seite liegt bei GitHub Pages, einem Dienst der GitHub, Inc., USA. Beim Aufruf verarbeitet GitHub technisch notwendige Daten, darunter deine IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen; siehe die Datenschutzerklärung von GitHub. Wir selbst erhalten diese Daten nicht.

Die Seite setzt keine Cookies, nutzt keine Analyse- oder Werbedienste und lädt keine Schriften oder Skripte von fremden Servern. Wählst du hell oder dunkel, merkt sich dein Browser diese Wahl lokal (localStorage); sie wird nicht übertragen.
